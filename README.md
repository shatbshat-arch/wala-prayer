# كتاب التهجئة | المرحلة التمهيدية 📖

موقع عربي تفاعلي جميل وسهل القراءة يعرض كتاب التهجئة كاملاً: الحروف، الحركات، التنوين، السكون، القلقلة، الشدة، الغنة، المدود، ضبط المصحف، وسورة الفاتحة — مع نطق صوتي وجدول متابعة.

المصدر: الهيئة العامة للشؤون الإسلامية والأوقاف — الطبعة الأولى 1437هـ / 2016م.

🌐 المعاينة الحية عبر GitHub Pages (بعد النشر)

## التشغيل محلياً
افتح ملف `index.html` مباشرة في المتصفح. الملف الأصلي: `كتاب التهجئة.pdf`.

## النشر
الموقع موقع ثابت (Static) — يعمل مباشرة على GitHub Pages بدون أي بناء.
